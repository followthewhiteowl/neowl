# Contribuer

*[🇬🇧 English](CONTRIBUTING.en.md)*

NeOwl est développé **en interne**. Nous **n'acceptons pas de pull requests
externes** pour le moment.

Les **issues** (rapports de bugs, retours d'usage) sont les bienvenues. Pour
échanger, voir le canal Telegram indiqué dans le README.

Si vous soumettez malgré tout une contribution et qu'elle est intégrée, vous
**conservez vos droits d'auteur** sur cette contribution et vous **accordez au
projet une licence irrévocable, mondiale, non-exclusive, gratuite et
sous-licenciable** de l'utiliser, la reproduire, la modifier, la distribuer et
la publier, y compris sous n'importe quelle licence. Ne soumettez du code que si
vous acceptez cette condition.
