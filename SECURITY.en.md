## Reporting a vulnerability

To report a security issue **privately**, use GitHub's
**Private Vulnerability Reporting**, from the repository page:
**Security → Report a vulnerability**.

Please do **not** open a public issue for a vulnerability.

Reports are handled on a best-effort basis; no response time is guaranteed at
this stage. Only the **latest released version** is considered.
